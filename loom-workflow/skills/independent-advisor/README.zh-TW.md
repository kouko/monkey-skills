# Independent Advisor

[English](README.md) | [日本語](README.ja.md) | **繁體中文**

> 針對當前的計畫或決策，去找**另一個執行者**要第二意見——更強的模型、更高的
> effort，或另一家廠商。變的是「誰來回答」，不是換視角。

---

## 概觀 — 這個 skill 做什麼

`loom-workflow:independent-advisor` 會去諮詢另一個執行者，而不是你正在對話的
這一個。執行者的能力用一組 tier 記錄：模型 tier 是 `economy` / `standard` /
`frontier`，effort 是 `low` / `medium` / `high`。這六個詞就是全部詞彙，記錄裡
不會把 tier 換成某家廠商的行銷名稱。

兩種模式：

- **`explore`** — 解法空間還開著。會生出一份獨立提案，把兩份提案正規化成同一
  個模板、匿名化，然後**在兩種卡片順序下**各盲判一次；判定者的順序偏誤會浮
  出來，而不是藏在單一次判定裡。
- **`audit`** — 成果已經存在。只跑單一 leg，帶完整脈絡去攻擊現行方案；這個模
  式不派盲提案的 leg。

模式是從一個**可引用的事實**決定的：commit 識別碼、PR 與其狀態、brief 裡的核
准句、或使用者自己的說法，並逐字記下來。沒有可引用的事實時，它會問你，而不是
自己猜。

---

## 何時用它，何時用姊妹 skill

| 情況 | 用哪個 |
|---|---|
| 想讓**另一個執行者**來回答（更強的模型、更高 effort、換一家廠商） | `loom-workflow:independent-advisor` |
| 同一個執行者，但想換一個**批評視角**看提案 | `loom-workflow:proposal-critique` |
| 特別懷疑過度設計 | `loom-workflow:complexity-critique` |

姊妹 skill 換的是視角，這支換的是執行者。它要花錢、而且會把材料送出這台機器，
所以「只是想換視角」時用它是選錯工具。

## 觸發語範例

- 「給我第二意見」
- 「換一個模型看看」
- 「找更強的模型評一下」
- 「換一家廠商的模型檢查」
- 「把 effort 調高再看一次」

## 誠實的前提 — 它不提供什麼

在你依賴結果之前先讀這段：

- **隱私範圍**。保證只涵蓋**派工包**——也就是刻意組裝並送出去的那份內容；它
  不涵蓋外部執行者跑起來之後能讀到的一切。凡是從它環境可以觸及的東西，都要
  當作它看得到。
- **盲判是對派工包的主張，不是對 leg 的主張**。挑戰方的派工包裡不會放你的方
  案；但它仍可能自己去讀授權範圍內的檔案，而那些檔案有可能寫著你的方案。所以
  報告會把「獨立形成」寫成有條件的說法，不是直接斷定。
- **一致不是強證據**。兩條 leg 讀同一份材料而得到同樣結論時，衡量的是材料，
  不是這個世界。那不是強證據，報告也不可以把它寫成強證據。
- **不宣稱覆蓋率**。你拿到的是「另一個執行者在一次派工中注意到什麼」的樣本，
  不是對整個風險空間的清查；這支 skill 不會把輸出說成看遍了所有面向。
