# Writing Lean

Token economy guidelines for skill documentation.

## Principles
- Prefer concise instructions over verbose explanations
- Use structured formats (bulleted lists, tables) over prose
- Extract detail to reference files behind Do NOT Load guards
- Target SKILL.md under 5,000 tokens (soft limit)

## Techniques
- Use references for deep dives
- Compress examples to minimal working cases
- Avoid repeating information across files
