# Blind-spot checklist ／盲區清單

Six common blind spots a plan quietly leans on. Offer this list ONCE
when a branch opens — not as a gate, not as a nag on every node.

## The six ／六個常見盲區

| Blind spot | 中文 |
|---|---|
| Resources stay unchanged | 資源不變 |
| Competitors stay static | 對手不動 |
| There is enough time | 時間夠 |
| The right people are available | 人找得到 |
| Regulation stays unchanged | 法規不變 |
| Demand persists | 需求持續 |

## The extra question ／額外一問

When a branch opens, also ask: 「這條路還踩在什麼上面？」— what else
is this path quietly standing on, beyond these six?

## Ask once, don't nag

Offer this checklist a single time, right when a branch opens. If the
user waves it off, move on — do not re-offer it at every subsequent
node in that branch. Any blind spot the user confirms matters becomes
an assumption file (see `assumptions/*.md` in node-schema.md), not a
recurring prompt.
