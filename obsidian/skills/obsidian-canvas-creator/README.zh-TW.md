# Obsidian Canvas Creator

[English](README.md) | [日本語](README.ja.md) | **繁體中文**

從文字內容建立 Obsidian Canvas 檔案，支援 MindMap 與 freeform 兩種佈局，另提供四種社群版型（看板／儀表板（首頁）／研究地圖／moodboard）與範本，以及輸出驗證腳本（`scripts/validate_canvas.py`）。
