# Obsidian Canvas Creator

[English](README.md) | [日本語](README.ja.md) | **繁體中文**

從文字內容建立 Obsidian Canvas 檔案，支援 MindMap 與 freeform 兩種佈局，另提供四種社群版型（看板／儀表板（首頁）／研究地圖／moodboard）與範本、輸出驗證腳本（`scripts/validate_canvas.py`），以及零外掛進階應用參考（巢狀畫布／研究雙畫布／資料管線文件化／稽核・事故檢討・onboarding 畫布／教師班級畫布／世界觀建構／Bases-in-canvas 1.9+）與巢狀工作區範本。
