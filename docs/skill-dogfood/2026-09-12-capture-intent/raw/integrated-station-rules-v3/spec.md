## Requirements

REQ-1 — Mute one project  
The product shall allow a project member to mute one project → Acceptance #1

REQ-2 — Stop subsequent project activity emails  
WHEN a project member mutes one project, the product shall stop subsequent activity emails for that project → Acceptance #2

REQ-3 — Leave other notifications and settings unchanged  
WHEN a project member mutes one project, the product shall leave in-app notifications and global settings unchanged → Acceptance #3

## UI flows

N/A — the confirmed intent does not authorize a UI, control, or surface; it specifies only the observable result after a project member mutes one project.

You will be able to mute one project. After you do, subsequent activity emails for that project stop, while in-app notifications and global settings remain unchanged.
