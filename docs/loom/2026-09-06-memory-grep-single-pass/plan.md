## Risks
1. The 2-second bound is a wall-clock assertion in CI: a loaded runner
   can breach it for reasons unrelated to the code. The perf test's
   primary assertion is the subprocess count (deterministic); the time
   bound is secondary and its failure message says so, so a red run is
   read correctly. agent-decided.
2. The five existing suites and the new ones must pass under macOS
   `/bin/bash` (3.2) and CI's bash 5; the adversary's probes run at least
   one suite explicitly under `/bin/bash`.
3. `git log -z` plus `%x1F` is a two-level separator; a subject containing
   `\x1F` would mis-split — the same exposure the old code accepted at
   `:416-418`, now documented in the same comment. No new exposure is
   introduced; none is removed.
4. Case-insensitive key matching in `%(trailers:key=)` is the one place
   the new path can silently include more than the old one; W1-01's
   lowercase-key fixture is the pin and W1-02's jq re-filter is the fix.
