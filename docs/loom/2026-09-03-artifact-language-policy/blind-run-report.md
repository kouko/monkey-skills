## 你要的東西，一條一條來

### 1. 一個新 change 走完流程，其規格、計畫、審查紀錄、佐證、探針測試、commit 訊息全為英文；只有意圖說明、盲跑報告、PR 內文用你的語言——由這份報告逐項列出檢查結果

- **證據**：commit `61dc0af5`、`2a45a57a` 的訊息內文；`git log` 全文檢查（37 則 commit 中只有這 2 則含中文，且都是引用）。

### 2. 契約模板資料夾裡每個檔案的說明文字都是英文；意圖模板欄位的意思不變

### 3. 六個站的說明各有一句語言規定，審查契約有「非英文內部產物記一個輕微提醒」的條文；審查規則的總數不變

- **我怎麼試的**：在六個相關站的說明文件裡搜尋語言規定的字句；打開審查契約找那條例外規定；跑一次列出全部審查規則的指令數一數規則總數。

- **證據**：六份說明文件各自命中；審查契約裡那段文字；規則清單指令輸出 27 行。

### 4. 本 repo 既有的中文文件不動，除了這次變更自己新增與確認的部分

- **我怎麼試的**：把這個分支和主幹的檔案差異列出來，篩出所有屬於「文件庫」路徑下被改動的檔案。
- **結果**：被改動或新增的檔案全部都在這次變更自己的資料夾裡，或是這次變更自己的意圖說明檔——沒有動到任何其他既有的中文文件。
- **證據**：分支對主幹的檔名差異清單，全部前綴都是這次變更自己的資料夾名。
- **判定**：符合。

### 5. 三個固定句型模板寫進契約：規格範例、審查意見的標籤開頭、探針測試的三段式命名；本次變更自己的產物逐項符合，由這份報告列出

- **我怎麼試的**：分別在規格模板、審查／挑戰／盲跑三份契約裡找這三個句型的定義；再回頭檢查這次變更自己產出的審查紀錄裡每一條意見文字，以及每一支測試的函式名稱（含這次變更收尾前才新增的第三份測試檔）。
- **結果**：
  - 規格模板的範例行採用了固定句型（「當…時，系統應該…」的其中一式）。
  - 三份契約都寫明了審查意見要以固定的九選一標籤開頭（如「issue」「nitpick」），以及測試函式要用「單元＿狀態＿預期結果」三段式命名。

  - 這次變更自己新增的三個測試檔（含收尾前新增的那個），加上語言檢查測試，共 34 個測試函式，全部符合三段式命名。
- **證據**：規格模板的範例行；三份契約各自的對應段落；審查紀錄 9 條意見文字逐一核對；測試函式名稱逐一核對輸出。

## 我幫你決定了的事

- **這次「三個固定句型模板」限定只採三種能機械檢查的，其他業界慣例（如 ADR、INVEST、瀏覽器臭蟲回報格式、模糊字禁用表）不採用** — 因為那些需要人的判斷才能檢查，不是規則能自動核對的。之後如果想加，要另開一次變更。
- **這次變更把自己當成第一個要符合新規定的樣本** — 也就是說，這次變更自己的規格、計畫、佐證、測試、commit 訊息，全部照新規定重寫成英文（意圖說明和這份報告除外）。這代表新規定從這次變更「就地」開始生效，不是另找一個未來的變更來驗證。
- **審查契約檔的內文一度超過原本的字數上限一個字，就把上限從 1340 調高到 1460** — 因為新加的語言規定文字讓契約變長了；調高上限比硬壓縮文字保真度更重要，所以選擇調高。之後如果契約還要加內容，這個新上限會是新的基準。
- **既有的中文計畫與佐證文件不回頭翻譯成英文** — 規則是「硬切換」，只對新開始的變更生效，不維護新舊雙語版本，也不補翻舊文件。這代表這個 repo 裡未來還是會同時存在中文的舊文件和英文的新文件，混合狀態會持續存在。
- **意圖說明本身的驗收項目維持你原本口語的中文寫法，不套用固定句型** — 因為那是「你自己確認過的原話」，不是要被機器核對的規格條文。
- **PRINCIPLES 訪談用的問卷模板本身是英文，但真正訪談你的時候會即時翻成你的語言** — 模板檔案本身是英文版的意義來源，執行訪談的那一刻才轉換成你看得懂的語言。
- **計畫文件裡原本的中文欄位標籤（如「檔」「測」「風」）改成了英文縮寫（Files/Test/Risk）** — 讓計畫文件也符合「內部產物用英文」的規定，但這個改動同時牽動了另一個站的說明文件裡引用這些標籤的地方，兩處一起改，避免兩邊對不上。

以上都不是我在審查過程中發現又打了折扣的問題——我核對了這次變更的審查紀錄，裡面 9 條意見沒有任何一條被標記為「已略過不處理」，所以沒有需要在這裡額外列出的「被駁回的重大發現」。

## 你可能還沒想清楚的地方

- 意圖說明裡自己承認「措辭固定會讓審查判決比較不飄」只是一個還沒被驗證過的假設——目前只是照著業界的固定寫法去寫，還沒有人實際量過「審查文件的句型固定之後，同一份文件被不同人／不同次審查出的結論是不是真的比較一致」。這件事目前無從驗證，只能之後觀察多次審查的結果自己判斷有沒有差別。
