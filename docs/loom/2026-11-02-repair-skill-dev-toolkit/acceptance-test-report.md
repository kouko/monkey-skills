## 我代你決定了什麼

- **判定界線** — 將例外誤報減少、真矛盾保留及漏報分開判斷；不因命令成功或測試通過就宣稱已可發布，也不要求模型永不犯錯。
- **已確認的漏報** — 同一資料格式的具名欄位被寫成兩個不同名稱，仍應列入核對結果；可以同時新增兩個欄位，不足以證明兩份欄位說明一致。這是具體文件契約缺陷，尚未觀察到實際讀取程式失敗。
- **分歧與盲審限制** — 兩位審查者都確認上述漏報；對平台打包依賴是否另構成事實矛盾仍有分歧，未算第二個已確認漏報。其中一位提前看到執行摘要，因此不把兩份審核都稱為完整軌跡盲審。
- **證據沿用** — 未變的建立與首次使用證據繼續有效；本機錄製資料重播無法證明新流程已在真實宿主完整執行，也沒有新的模型準確度校準。
- **歷史界線** — 舊誤報、未完成的大型測試、提早讀取參考資料及耗盡重試後的殘留檔案與再派工建議均保留；本輪沒有新增派工、重設修補次數或再修來源。
- **被駁回的嚴重發現** — 本輪沒有交付遭駁回的重要或致命發現；已確認的漏報保持未解決。較早對跨次比較會誤採用的致命判斷曾因新畫面與解碼證據限縮，歷史處理仍保留。
