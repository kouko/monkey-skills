## 我代你決定了什麼

- **通過的界線** — 分開判斷程式執行、報告內容與未測環境；不以整體命令成功或模型限制聲明消除已重現的驗收失敗，也不要求有限樣本保證所有模型永不出錯。
- **證據沿用** — 僅沿用修正差異完全未觸及的三項結果；較早的建立案例及完整測試另先核對程式內容相同。這不等於重新執行外部模型或重新安裝插件。
- **判斷分歧** — 兩位獨立審查者對平台打包文字的嚴重程度，以及抽出參考文件時的風險等級差異，保留不同判斷；共同確認的例外誤報仍列為缺陷。
- **首次使用限制** — 原生執行曾多讀一個後續檢查節及提早載入參考文件，因此不宣稱讀取範圍完全合規；準備與停止產物本身已核對。
- **未完成的重試** — 已耗盡重試的案例確實停止合併，但未完成檔案仍留在可合併名稱下，且回覆建議再派一次；本次沒有實際第三次派工或錯誤合併。
- **歷史證據** — 保留原本失敗的測試，沒有把更換正控制解釋成舊測試轉為通過；已耗盡的修補嘗試次數不重設。
- **被駁回的嚴重發現** — 主代理未交付本輪遭駁回的重要或致命發現；先前對跨次比較會誤採用的致命判斷，因新畫面及選擇解碼正確而限縮，這項歷史處理仍保留於舊證據。
